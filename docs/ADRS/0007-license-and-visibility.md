# ADR-0007: License and repository visibility
Status: open — awaiting founder decision

**Facts (verified 2026-11-04).** The GitHub repository `AdityaJak/Human-possibility-engine` already exists and reports visibility **public**. The spec asks for a PRIVATE repository until the founder authorises public release. This session has no tool to change repository visibility.

**Decision.** No license is assigned (all rights reserved by default) until the founder chooses. Code is pushed only with the founder's explicit go-ahead given the public visibility; otherwise the founder should switch the repository to private in GitHub settings first.
