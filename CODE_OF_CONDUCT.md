# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, critique ideas not people, and prioritise scientific honesty — including about our own negative results. Report unacceptable behaviour privately to the repository owner. Maintainers may remove contributions or contributors that violate these standards.
